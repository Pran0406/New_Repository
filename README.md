## 📌 Project Overview

This project focuses on **Airline Aviation Data Analysis** using **Microsoft Excel** to transform raw aviation data into meaningful business insights.

The analysis was completed as part of my **Data Analytics training/internship at UV Technocrats**, where I applied practical data analytics techniques including **data cleaning, data transformation, exploratory analysis, KPI development, Pivot Tables, and data visualization**.

The objective was to analyze airline operational and performance data, identify important trends and patterns, and generate insights that could support **data-driven decision-making in the aviation industry**.

## 🎯 Objectives

* Analyze airline and aviation-related operational data.
* Clean and prepare raw datasets for analysis.
* Identify important business and operational KPIs.
* Analyze airline performance and trends.
* Compare performance across relevant categories.

* Build interactive Excel-based analysis and visualizations.

## 📊 Analysis Performed

The project involved analyzing aviation data from multiple perspectives, including:

### ✈️ Airline Performance Analysis

* Compared airline-level performance.
* Identified high- and low-performing categories.
* Analyzed operational trends across airlines.
* Evaluated variations in performance indicators.

### 🛫 Flight & Operational Analysis

* Analyzed flight-related records.
* Examined operational patterns.
* Identified trends and variations in aviation activity.
* Investigated potential operational exceptions.

### 📈 Trend Analysis

* Analyzed changes over time.
* Identified increasing and decreasing trends.
* Compared performance across different periods.
* Used Excel visualizations to communicate findings.

### 🔎 KPI Analysis

Developed analytical metrics to evaluate aviation performance, such as:

* Total Flights
* Airline-wise Flight Count
* Performance by Category
* Operational Trends
* Average Performance Metrics
* Category-wise Comparisons
* Percentage Contributions
